# PastePing 使用说明（给用户看的一份）

面向拿到软件的普通用户。**这份文档只讲怎么用，不讲怎么改代码** ——
改代码请看 [`code-tour.md`](code-tour.md)。

---

## 1. 这是什么

一个**安静的剪贴板安全提醒**：当你把某些内容复制到别处之前，它提醒你一次。

* 不新增任何快捷键，不改变你的复制习惯；
* **只提醒，不阻断** —— 不会拦截、不会弹窗打断你，也不会替你改内容；
* 完全本地运行，**不联网**；
* 唯一入口是**托盘图标右键菜单**，没有主窗口。

---

## 2. 怎么知道它在运行：看托盘图标

PastePing 的图标是一个**深灰圆角方块 + 白色大写「P」**。状态只有两种：

| 图标 | 含义 |
| --- | --- |
| 深灰底白色「P」 | 正在运行，待命中 |
| **变红**的白色「P」 | 刚检测到内容会提醒你，**2 秒后自动恢复灰色** |

托盘图标可能被 Windows 收进"隐藏的图标"里（点托盘左侧的 `^` 展开）。
建议把它拖到常驻区，这样红色闪烁才看得见 —— **变红是本工具最可靠的提醒信号**，
系统气泡通知有可能被"专注助手 / 勿扰模式"静音。

---

## 3. 它会在什么时候提醒你

* 三类检测：内部批注标记、AI 生成残留、法定敏感信息（身份证 / 手机号 / API Key / 银行卡）；
* 命中后：图标变红 2 秒 + 系统通知；
* 同一段内容 60 秒内只提醒一次；
* 「暂停 5 分钟 / 暂停 1 小时」与「敏感提醒」总开关。

---

## 4. 全部功能都免费，装上就能用

**PastePing 没有付费解锁这一步。** 装上就拥有全部功能：

- **自动清洗粘贴**：托盘菜单里直接勾选即可（默认关闭，勾上后命中时会先清洗再写回剪贴板）；
- **格式转换**：Markdown → Word、网页表格 → Excel，直接点；
- **打开结果文件夹**、**撤销上次清洗**：都在菜单里。

> **没有内购、没有功能锁、没有试用期、没有使用次数或长度限制。**
> 源码以 GPL-3.0 开放，任何人都不能拿它做一个「闭源 + 收费解锁」的版本。

### 菜单里的「支持开发者」是什么？

它是一个**纯自愿的打赏入口，不改变任何功能** —— 它做的事情只有一件：
用你的默认浏览器打开赞助页。仅此而已。

* **你不会收到任何「码」**，也没有任何需要输入的地方；
* 软件里**没有任何需要你填写的字段**；
* 赞助前后，菜单长一样、行为一样、功能一样。

> 如果这个工具帮到了你，再考虑赞助；不赞助也完全不影响使用。
> 赞助是给开发者的鼓励，不是购买。

## 5. 「我复制了，但没有任何提醒」

先明确一件事：**只有命中规则才会提醒**，复制普通文字本来就不该有反应 —— 否则就成了骚扰。

**用这两段之一自测**（都能稳定触发）：

* 复制：`这是一份内部资料，请勿外传。`
* 复制：`11010519491231002X`

如果这两段也毫无反应，按顺序排查：

| 可能原因 | 怎么确认 |
| --- | --- |
| 提醒被暂停 / 总开关关了 | 托盘右键看「敏感提醒」是否勾选、是否停在「暂停 5 分钟」 |
| 系统通知被静音 | 看**图标有没有变红 2 秒**。变红说明检测是好的，只是气泡被系统静音了（关闭专注助手即可） |
| 剪贴板监听没启动成功 | 程序启动时会主动弹一次「监听启动失败」提示；没有这个提示但完全无反应，看文末日志 |
| 内容确实没命中规则 | 见下表 |

**注意（2026-10 起的行为变化）**：为了压掉误报，以下写法现在**需要同屏出现"内部 / 勿外传 / 保密 / 草案 / 待定"这类词**才会提醒 ——
单独出现不再提醒：`备注：`、`注：`、`仅供参考`、`> 引用块`、`—— 补充说明`、单独的 `【…】`。
固定关键词（`内部资料`、`转发文案`、`勿外传`）、AI 残留特征（`以下是`、`当然可以`、`希望对你有帮助`…）、
以及全部敏感信息规则**不受影响**。

## 6. 「点了菜单没反应」怎么办

**从 2026-10 的版本起，任何一个菜单项点下去都必然有可见响应**（弹窗 / 通知 / 打开窗口），
不会再出现「点了什么也没发生」。每个菜单动作都做了统一兜底：即使内部出错，
也会弹出提示并把原因记进日志，不会静默。

以「支持开发者」为例，正常情况下点一下，浏览器就会直接打开赞助页。

| 现象 | 说明与处理 |
| --- | --- |
| 浏览器没打开 | 程序会改为**把赞助页地址显示在弹窗里**，复制到浏览器打开即可 |
| 「敏感提醒」「暂停」点了没感觉 | 现在每次点击都会弹一条通知说明当前状态（如「已暂停 5 分钟」）；暂停期间菜单里会出现「恢复提醒（还剩约 N 分钟）」 |
| 「自动清洗粘贴」「格式转换」「撤销上次清洗」点了没反应 | **不需要任何解锁** —— 这些入口任何时候都该直接生效。若真无响应，见文末日志 |
| 整个菜单点任何项都无反应 | 见文末日志，把最后 20 行发回即可定位 |

### 「关于」点了确定窗口却不消失？（2026-10 已修）

曾经出现过一个真实故障：**「关于」连点两次会叠出两个一模一样的窗口**，
点一次「确定」只关掉上面那个，底下还压着一个 —— 看起来就像「点了确定窗口不消失」。

根因是弹窗开着的期间，托盘菜单仍然能点，于是能叠出第二个窗口。
现在**同一时刻只允许存在一个对话框**：

- 已有窗口在屏幕上时，再点会弹窗的菜单项**不会再叠新窗口**，
  而是把已有窗口提到最前面（这本身就是一次可见响应），并记进日志；
- 程序里能弹窗的地方其实只有一个：只读的「关于」框（外加浏览器打不开时给地址的那个提示）。
  它们共用同一把闸门，互相之间也不会叠。

| 现象 | 说明与处理 |
| --- | --- |
| 点了「关于」但没看到新窗口 | 屏幕上已有一个窗口在等你确认（它会被提到最前面）。先处理掉那一个 |
| 点「确定」后窗口还在 | 请确认屏幕上是不是还有**别的**等待确认的窗口（例如浏览器打不开时的地址提示框）；本版本已不会叠同样的窗口 |

## 7. 日志在哪（排查用）

```
%APPDATA%\PastePing\pasteping.log
```

打开方法：按 `Win + R`，粘贴 `%APPDATA%\PastePing`，回车即可看到该文件。

日志里**只记录长度与哈希前 8 位、命中的规则名、以及每一步的决策**，
**绝不包含你的剪贴板内容**。它可以放心发给开发者用于定位问题。

---

## 8. 隐私

* 不联网、不上传：客户端对剪贴板内容的处理全部在本机内存中完成；
* 提醒里显示的敏感信息**已脱敏**（如 `110***********X`）；
* 程序自动写盘的文件**只有一个**：上面的诊断日志（以及你主动做格式转换时生成的文档）。
  没有配置文件、没有状态文件、也没有任何「授权标记」。
