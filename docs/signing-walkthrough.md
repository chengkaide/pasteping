# 代码签名：从下单到签好 exe 的完整流程

> 面向「我现在就去买证书、把它签上」的场景。选购对比与原理见 `docs/code-signing.md`。
> 本文只讲**怎么做**，按顺序走即可。

---

## 〇、先花一分钟确认：你真的需要买吗

| 方案 | 花费 | 效果 |
| --- | --- | --- |
| **让用户「解除锁定」** | **¥0** | **已实测有效**：文件不带网络标记，就不会被 SmartScreen 拦（见 `code-signing.md` 第七节） |

- 准备公开分发、让陌生用户下载 → 值得买，因为"让人先去点更多信息"会实实在在劝退一部分人。

**本文余下内容 = 你已经决定要买。**

## 一、买哪个（2026-10 价格）

| 型号 | 价格 | 个人能买 | 说明 |
| --- | --- | --- | --- |
| **Certum 个人版（推荐）** | **¥600/年** | ✅ **只要身份证** | 云签名，无需 UKey |
| Certum 3 年期套餐 | ≈¥1500（约 ¥500/年） | ✅ | 更省，但中途会重新签发一次（见下） |
| Certum OV（普通版） | ¥880/年 | ⚠️ 要营业执照 | 个人办不了 |
| Sectigo 个人版 | ¥3200/年 | ✅ | 太贵，没必要 |

**别买 EV**：EV 自 2024 年起不再"首次下载即免警告"，为绕 SmartScreen 买它是白花钱。

> **为什么说"3 年期会中途重签"**：自 2026-02-27 起，单张证书最长有效期 459 天。
> 买 3 年期 = 覆盖 2–3 次签发，属于正常流程，**不是额外收费**。

**在哪儿买**：Certum 在国内通过授权服务商销售（可用人民币、有中文客服与发票），
常见的有环度科技（`certumca.cn`）、SSLDUN 等。认准「**个人版**」+「**云签名 / SimplySign**」两个关键词。

## 二、全流程一览（含时间预期）

```
下单支付 → 提交材料 → 身份验证 → 签发 → 激活 SimplySign → 本机试签 → 正式签 exe
  10 分钟    10 分钟    1~3 天      1~3 天     20 分钟        15 分钟     5 分钟
```

**整体预留 3~5 个工作日**（官方口径是最长 7 个工作日）。
⚠️ **不要卡在上线前一天才办** —— 身份核验可能需要你补材料。

## 三、逐步操作

### 第 1 步：准备材料（个人版）

- [ ] **身份证正反面**照片/扫描（清晰、四角完整、无反光）
- [ ] **手机号**（要能接电话/短信，审核期可能回访）
- [ ] **邮箱**（证书激活链接会发到这里）
- [ ] 若服务商额外要求：手机号实名截图、话费发票等辅助证明

> 填写的**姓名必须与身份证完全一致**。这个名字会写进证书，用户点开
> 「数字签名」看到的就是它 —— 写错了要重新走一遍验证。

### 第 2 步：下单支付

- [ ] 在服务商官网选择 **Certum 代码签名证书 → 个人版**
- [ ] 有效期按需选（1 年 / 3 年）
- [ ] 支付（支付宝 / 微信 / 对公）
- [ ] **索要发票**（个人版也能开，以后用得上）

### 第 3 步：身份验证（关键环节）

- [ ] 服务商提交你的材料给 Certum
- [ ] Certum 按规则核验身份，通常会让你走一次**人脸/视频核验**
      （网页或 App 引导，需摄像头）
- [ ] 期间保持手机畅通，可能电话回访或邮件补充材料

> 这一步**由 Certum 决定**，服务商说不上话。材料越齐越快。

### 第 4 步：激活证书（云签名）

通过验证后，你会收到**两封邮件**：

- [ ] 邮件 A：一个**激活码**（一串字符）
- [ ] 邮件 B：**激活链接** + SimplySign 手机 App 的下载指引

操作顺序：

1. [ ] 手机上装 **SimplySign** App
2. [ ] 电脑上打开邮件 B 的激活链接 → 输入邮件 A 的激活码
3. [ ] 网页会显示一个**二维码** → 用手机 App 扫码完成绑定
   （App 里选"我将用它生成令牌 / generate tokens"）
4. [ ] 下载并安装 **SimplySign Desktop**（Windows 版）
5. [ ] 打开它，输入邮箱；在手机 App 里生成**一次性令牌**，填进桌面端
6. [ ] 登录成功 → 桌面端常驻托盘，能看到你的证书

> **签名时手机要能联网**（每次签名要用手机 App 生成令牌）。
> **私钥存在云端 HSM，不可导出**，也不能随意复制到多台电脑。

### 第 5 步：本机确认证书已就位

先看本机有没有这张证书：

```powershell
Get-ChildItem Cert:\CurrentUser\My | Format-Table Subject, Thumbprint, NotAfter
```

应能看到一条 **Subject 里带你的名字**、颁发者为 Certum 的证书。
把 `Thumbprint`（证书指纹）复制下来。

本仓库的签名工具也带了同样的能力：

```bash
python tools/sign_exe.py --hash        # 看 SHA256 与当前签名状态
```

### 第 6 步：先用一个测试文件试签（强烈建议）

拿个无关紧要的文件，把整条链路（含时间戳）先跑通一次：

```bash
python tools/sign_exe.py --sign --thumbprint <证书指纹> --dry-run
```

`--dry-run` 只打印命令不执行 —— 先确认命令长得对，再去掉它真签：

```bash
python tools/sign_exe.py --sign --thumbprint <证书指纹>
```

脚本会自动：调 `signtool sign`（带 `/fd SHA256 /td SHA256 /tr 时间戳`）→
再跑 `signtool verify /pa /v` 核验 → 复述 SHA256。

> **时间戳（`/tr`）不能省**：带上它，证书过期后已发布的签名**依然有效**；
> 不带，证书一到期，用户那边签名立刻变"无效"。

### 第 7 步：正式签 exe

**每次 `python tools/build_exe.py` 之后都必须重新签** —— 重打包会生成全新文件，
签名不会跟着走。把「打包 → 签名」当成一个不可拆分的动作。

```bash
python tools/build_exe.py                        # 1) 打包（会自动带上 assets/pasteping.ico）
python tools/sign_exe.py --sign --thumbprint <证书指纹>   # 2) 签名
python tools/sign_exe.py --hash                  # 3) 确认：状态应显示 Valid
```

### 第 8 步：分发前把下载页更新掉

- [ ] 把**新的 SHA256** 贴到下载页（重签会改变哈希，旧的一定要换掉）
- [ ] 说明这是**已签名**版本，发布者显示为你的名字
- [ ] 保留「完全本地运行、不联网、不上传剪贴板」的说明

## 四、签完就不会有警告了吗？

**不一定立刻。**

- 签名**消除了「未知发布者」**，用户能在签名信息里看到你的名字；
- 但 **SmartScreen 的"这软件安全吗"还看信誉**：刚签的头几份文件仍可能提示，
  需要**下载量累积**（数周到数月）。
- 好消息：**一旦建立声誉，后续每次发布都受益**，这也是签名的长期价值。

**想尽快建立信誉**：保持同一张证书、稳定的下载渠道、别频繁改签名主体。

## 五、坑清单（都是真金白银换来的）

1. **私钥进不了仓库** —— Certum 是云签名，本来就不落盘；但也**不要**去申请导出版本。
   `.gitignore` 已忽略 `*.pem`，pfx 也要一起忽略。
2. **证书不能多机乱用** —— 云签名靠"虚拟智能卡"，同一账号换机需要重新走手机验证。
3. **重新打包必须重新签**（第 7 步），这是最容易漏的一条。
4. **`/tr` 时间戳不能省**。
5. **签名主体名写错**就要重新走验证，务必按身份证填。
6. **换机器后 `signtool` 可能找不到** —— 它随 Windows SDK 提供，
   也可 `winget install Microsoft.WindowsSDK.10.0.22621`（只勾 Application Signing Tools 即可）。

## 六、本仓库已有的工具

| 命令 | 作用 |
| --- | --- |
| `python tools/make_icon.py` | 生成 `assets/pasteping.ico`（打包时自动刷新，不用手动跑） |
| `python tools/build_exe.py` | 打包 + 私钥/模块双向安全检查 + 打印 SHA256 与签名状态 |
| `python tools/sign_exe.py --hash` | 查大小、SHA256、签名状态 |
| `python tools/sign_exe.py --sign --thumbprint <指纹>` | 用系统里的证书（云签名走这条）签名 |
| `python tools/sign_exe.py --sign --pfx <文件> --password <口令>` | 用 pfx 文件签名（本方案用不到） |
| `python tools/sign_exe.py ... --dry-run` | 只打印命令、不执行 |
